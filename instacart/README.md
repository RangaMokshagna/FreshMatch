# Put the real dataset here

Copy these five extracted CSV files into this folder:

- orders.csv
- order_products__prior.csv
- products.csv
- aisles.csv
- departments.csv

The CSVs must sit directly beside this README, not inside another archive folder.
If a file still ends in .zip, extract it first. The downloaded archive can also be
extracted with `scripts/prepare_instacart.py` into an empty directory.

CSV datasets in this folder are tracked with Git LFS. Install Git LFS and run `git lfs pull` after cloning to download them.
See [Windows setup](../WINDOWS_SETUP.md) for installation and training commands.
